# Roteiro 04 — Express.js

## Executar

1. Instale o Node.js.
2. Abra um terminal nesta pasta.
3. Execute `npm install express`.
4. Execute `node server.js`.
5. Teste as rotas:
   - http://localhost:3000/
   - http://localhost:3000/sobre
   - http://localhost:3000/contato
   - http://localhost:3000/api/produto
   - http://localhost:3000/produto/15
   - http://localhost:3000/busca?nome=Maria
   - http://localhost:3000/api/alunos

Para interromper o servidor, pressione Ctrl+C no terminal.
