# Aula 05 — Exercícios resolvidos

Requisitos: Node.js e npm instalados.

1. Abra esta pasta no terminal.
2. Execute `npm install`.
3. Execute `npm start`.
4. Acesse as rotas no navegador:
   - http://localhost:3000/usuarios
   - http://localhost:3000/usuarios/1
   - http://localhost:3000/produtos
   - http://localhost:3000/produtos/1
   - http://localhost:3000/produtos/abc (400)
   - http://localhost:3000/produtos/99 (404)
   - http://localhost:3000/produtos/total
